# 实验一控制变量方案（33 次训练与测试已完成）

基础模型对比完成后，进一步研究课件要求的深度、参数量和 batch size。以下方案对应的 Fashion-MNIST 11 配置 × 3 种子已完成训练、独立测试和核验；结果见 reports/ablations/summary.md，解释见 reports/ablations/结果解读.md。方案之外的扩展不视为已执行。

模型已实现于 `controlled_cnn.py`，全部配置已通过 CPU 前向/反向传播、卷积层数与参数量核对。`prepare_ablation_plan.py` 生成 `reports/ablation_plan.json`：共享配置去重后共 11 种，三个种子共计划 33 次训练。固定计划文件保留训练前状态，实际执行进度单独写入 reports/ablations/progress.json。

## 共用设置

- 主数据集：Fashion-MNIST，复用已有固定分层划分。
- 同一 CNN 家族：3 个阶段，各阶段输出通道依次为 W、2W、4W。阶段内重复 d 次 Conv(3×3, padding=1, bias=False) + BatchNorm + ReLU，阶段末用 2×2 最大池化。最后全局平均池化、Linear(4W,10)。
- “深度”定义为卷积层数 3d，不把 BN、激活和池化算作卷积层。
- 从随机初始化训练，固定 Adam、lr=0.001、20 epochs、AMP；除研究的变量外，其余设置一致。
- 每个关键配置采用种子 42、43、44，比较均值和标准差，保留单次结果。
- 按验证损失选权重，全部配置预先确定后再独立测试；不根据测试集选择“最好看的”配置或种子。

## 实验组

| 组别 | 变化因素 | 固定条件 | 建议配置 |
|---|---|---|---|
| 深度 | 卷积层数 | W=32、batch=128 | d=1/2/3，即 3/6/9 层 |
| 宽度/容量 | 通道数 | d=2、batch=128 | W=16/32/64 |
| 批量大小 | batch size | d=2、W=32 | 32/64/128/256 |
| 参数量近似匹配 | 深度与补偿宽度 | batch=128 | (d=1,W=48)、(d=2,W=27)、(d=3,W=21) |

增加深度时参数量通常也增加，所以“固定宽度”的深度实验仍存在容量变化。近似匹配参数量的补充组能缓解这个问题，但也同时改变了宽度，解释时仍需承认限制。

按上面的结构，理论参数量为：

`P(d,W) = [90 + 189(d-1)]W² + [63 + 14(d-1)]W + 10`

其中包含卷积、BN 的可训练参数和最终分类层。实现后须通过代码重新统计并核对。近似匹配组的理论值分别为 210394、205480、208309，最大与最小相差约 2.4%。

已完成上述代码核对，实际参数量与公式一致。固定 W=32 时，3/6/9 个卷积层分别有 94186/288170/482154 个参数；固定 6 个卷积层时，W=16/32/64 分别有 72666/288170/1147722 个参数。

## batch size 的解释

固定 epoch 时，每轮看到的样本相同，但 batch 越小，优化器更新次数越多。这一组回答的是“相同数据遍历预算下，不同 batch 的训练效果和成本”，不能声称已经固定了所有优化条件。

应同时记录：每轮 batch 数、总更新次数、总耗时、峰值显存、训练/验证曲线。可以额外增加固定更新次数的补充实验，但应独立成组，不能与固定 epoch 的结果混写。

## 结果如何呈现

1. 深度对准确率、参数量和计算量的关系。
2. 参数量对训练/验证差距的影响，结合欠拟合与过拟合解释。
3. batch size 对准确率、速度、显存和更新次数的影响。
4. 三个种子的均值与标准差；小幅差异不直接表述为稳定优势。
5. 可选扩展（尚未执行）：在 HWDB10 上复核少量关键配置，观察小样本场景是否支持相同结论。本轮控制变量结论限定于 Fashion-MNIST。
