# 本实验实际使用的模型

报告和答辩应描述实际运行的代码。当前比较的是经典模型的 PyTorch/Torchvision 小图适配版本，不应声称逐项复刻原始论文。

所有模型的共同输入是 N×1×32×32，输出为 N×10 logits，不使用预训练权重。代码入口为 models.py。

| 模型 | 需要准确说明的实现细节 |
|---|---|
| MLP | 展平 1024 像素，经 256、128 两个 ReLU 隐藏层，输出 10 类 |
| LeNet | 两个 5×5 卷积，通道数 6、16；ReLU 与最大池化；400→120→84→10 全连接；这是 LeNet 风格版本 |
| AlexNet | 使用 torchvision 构建主体，灰度 3×3 首层，stride=1，去掉入口最大池化；保留大尺寸全连接层和 Dropout；固定输入下以等价普通平均池化兼容 CUDA 严格确定性训练 |
| GoogLeNet | 使用 torchvision 的 Inception 主体与 BN；修改灰度入口、去掉前两个最大池化；不使用辅助分类器；关闭 RGB 特定输入变换；采用模块默认初始化 |
| ResNet-18 | 使用 torchvision 的 18 层残差结构；首层改为灰度 3×3、stride=1，去掉入口最大池化；其余残差阶段保留 |

## GoogLeNet 分支的一个具体细节

本机 torchvision 0.26.0 的 googlenet.py 中，Inception.branch3 的空间卷积实际为 3×3，源码注释明确指出这是保留的历史实现。虽然构造参数仍命名为 ch5x5/ch5x5red，但不能仅根据变量名在报告里把这部分写成 5×5。

本实验保留这个库实现，以确保模型定义明确可复现；若后续实现原论文分支，应作为另一种模型变体独立实验。

## 参数量不等于计算量

根据实际模型前向过程统计，单张 32×32 图像的卷积与全连接 MACs 为：

| 模型 | 参数量 | Conv/Linear MACs |
|---|---:|---:|
| MLP | 296586 | 296192 |
| LeNet | 61706 | 416520 |
| AlexNet | 57022154 | 850804736 |
| GoogLeNet | 5601322 | 1449863168 |
| ResNet-18 | 11172810 | 554243072 |

一个卷积核在多个空间位置重复使用，所以较少的参数也可能对应较多的乘加。MACs 还不包括 BN、激活、池化、反向传播与优化器，不能直接换算成训练秒数。实际耗时还受数值精度、GPU、内存访问和算子实现影响。

统计脚本为 model_stats.py，机器可读结果为 reports/model_stats.json。模型代码发生变化后，应重新统计。

## 数值精度

完整主对比使用 AMP：部分适合的 GPU 算子使用 FP16，参数与 Adam 状态仍为 FP32，并采用 GradScaler 缩放梯度。验证与测试使用相同 autocast 设置。

早期 FP32 结果独立保留。改变精度可能改变舍入误差及后续优化轨迹，不能要求 AMP 与 FP32 成绩逐位相同，也不能从一次运行的差异就断言某种精度更准确。
