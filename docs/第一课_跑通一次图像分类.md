# 第一课：看懂一次图像分类实验

本阶段学习目标：能解释一张图片如何成为预测结果，训练如何改变参数，以及验证集和测试集分别承担什么作用。

## 任务与数据

Fashion-MNIST 是 10 类服饰图像。输入是灰度像素，标签是 0 到 9 的整数。模型输出每一类别的原始分数（logits），分数最高的类别就是预测类别。

原训练集有 60000 张图。我们固定划出 6000 张作验证，剩下 54000 张用于计算梯度。原测试集 10000 张只用于最终评估。验证集帮助选择模型，测试集估计模型对未参与选择的数据的表现。

## LeNet 中的张量变化

`N` 表示一个批量中的图片数。32×32 是本实验统一的输入大小。

| 操作 | 输出形状 | 解释 |
|---|---|---|
| 输入 | N×1×32×32 | 1 是灰度通道数 |
| 5×5 卷积，6 个输出通道 | N×6×28×28 | 每个卷积核学习一种局部模式 |
| ReLU | N×6×28×28 | 负值置零，引入非线性 |
| 2×2 最大池化 | N×6×14×14 | 缩小空间尺寸 |
| 5×5 卷积，16 个输出通道 | N×16×10×10 | 组合前一层局部特征 |
| ReLU + 2×2 池化 | N×16×5×5 | 得到更紧凑的特征 |
| Flatten | N×400 | 16×5×5=400 |
| 全连接 + ReLU | N×120 | 综合图像特征 |
| 全连接 + ReLU | N×84 | 进一步变换特征 |
| 全连接 | N×10 | 得到 10 类 logits |

不填充、步长为 1 的卷积，空间输出尺寸为 `输入尺寸 - 卷积核尺寸 + 1`，因此 32 经过 5×5 卷积变为 28。

## 一次训练步骤

```python
optimizer.zero_grad(set_to_none=True)  # 清除上个 batch 的梯度
logits = model(images)                # 前向传播
loss = criterion(logits, labels)      # 预测与真实标签之间的误差
loss.backward()                       # 计算参数对损失的梯度
optimizer.step()                     # 根据梯度更新参数
```

`CrossEntropyLoss` 内部处理 logits 对应的对数概率，不需要先给模型输出加 Softmax。预测类别只需 `logits.argmax(1)`。

一个 batch 是一次参数更新使用的样本。一个 epoch 表示完整遍历一次训练集。54000 张训练图、batch=128 时，每轮有 422 个 batch，最后一个不足 128 张但仍参与训练。

## 训练与验证为何分开

训练使用 `model.train()` 切换训练模式，在启用梯度记录的环境中执行反向传播和优化器更新。验证使用 `model.eval()` 切换评估模式，同时用 `no_grad()`（或 `set_grad_enabled(False)`）关闭梯度记录，不调用优化器更新。对于含 Dropout、BatchNorm 的网络，train/eval 会影响这些层的行为。`eval()` 本身不会关闭梯度；`no_grad()` 也不能代替 `eval()`。

## 怎么看曲线

- 训练和验证损失都下降：目前模型在训练、验证数据上都在改善。
- 训练损失继续下降，验证损失上升：可能出现过拟合，需结合趋势与样本量判断。
- 两者都较高且变化很小：可能是训练不足、模型能力不足，或实现/学习率问题。
- 验证准确率上升但验证损失上升：可能少量错误预测变得非常自信，两个指标并不总是同步。

单次波动不等于明确结论。第一轮只建立基准，模型优劣需要统一协议下比较，重要结论还需重复运行。
