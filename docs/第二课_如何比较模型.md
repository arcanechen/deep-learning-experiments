# 第二课：如何比较模型，并解释实验结果

本阶段目标：理解一组模型对比到底能说明什么，学会从日志和错误样例中找证据。

## 先确定比较条件

同一数据集的所有模型共用同一训练/验证/测试划分。训练种子、优化器、学习率、批量大小和最大轮数一致。各模型都按最低验证损失选择权重，再做独立测试。

这让比较有明确边界，但不等于每个模型都处于最佳状态。不同模型可能需要不同学习率或训练时间。如果一个模型表现不好，应先检查训练、验证曲线，不能马上得出这种架构不好的结论。

本轮 MNIST 和 Fashion-MNIST 各训练 10 轮；汉字数据训练 50 轮。汉字训练集只有 2159 张，batch=128 时每轮 17 次参数更新；50 轮约 850 次更新。Fashion-MNIST 每轮 422 次更新，10 轮约 4220 次。所以不能把不同数据集的“相同轮数”当成相同训练工作量。

## 区分三个问题

| 你想问的问题 | 需要观察的证据 |
|---|---|
| 模型是否学会拟合训练数据？ | 训练损失和训练准确率 |
| 训练到哪一轮更适合未参与梯度更新的数据？ | 验证损失及选中的轮数 |
| 确定配置后，对独立数据表现怎样？ | 测试准确率、Macro-F1、混淆矩阵、错误样例 |

测试结果不参与选最佳轮数或调整学习率。若不断根据测试结果改模型，测试集就逐渐承担了验证集的作用，最终成绩会偏乐观。

## 读懂准确率与 Macro-F1

准确率是全部预测中正确的比例。Macro-F1 先计算每一类的 F1，再对类别取平均，因此能帮助观察模型是否偏向少数容易识别的类别。

在汉字测试集上，一张图片对应约 0.17 个百分点（1/597）。小幅变化可能只来自少数错误样本；而且同一个书写人的样本有关联，不能简单把所有图片当作完全独立的观测。

混淆矩阵每行代表真实类别，每列代表预测类别。对角线是正确分类，非对角元素说明哪些类别容易混淆。判断原因时，要实际看错误图片，而不是只看类别名字。

## 参数量和深度如何分析

早期 FP32 参考运行的一个具体例子（不是后续 AMP 主对比）：汉字 LeNet 在第 28 轮的验证损失最低（约 0.2419），对应验证准确率 93.31%；第 39 轮验证准确率达到 94.98%，但验证损失略高（约 0.2467）。因为提前约定按损失选模，最终仍使用第 28 轮。两种指标关注点不同，不能看到结果后随意更换规则。

MLP 与 LeNet 的结构差异不止参数量，还包括局部连接、权重共享、空间结构处理方式等。它们的结果差异不能单独归因于参数量。

要研究参数量，下一阶段可以固定网络深度，调整通道数。要研究深度，可以在同一网络家族中改变卷积层数，并增加近似匹配参数量的对照。这样才能更清楚地解释变化来源。

## 训练准确率低于验证准确率一定有问题吗？

不一定。训练准确率是在一轮内不断变化的参数上累计的，验证准确率是在这一轮结束后用固定参数计算的。含 Dropout 的模型在训练时还会随机屏蔽部分激活，验证时则关闭。应结合实现和整体趋势判断。

## 本轮结果的边界

目前是每个组合一个训练种子的基准。它可以发现明显问题、建立初步比较，却不能证明微小优势稳定存在。关键结论还需要重复训练并报告均值和标准差。

另外，汉字数据是明确固定的官方自选十类子集；它的成绩不能直接与使用另一组汉字、另一种划分的实验横向比较。

## 自测

1. 为什么 MLP 参数更多，却不一定优于 LeNet？
2. 为什么不直接取测试准确率最高的一轮作为最终模型？
3. 两个模型测试准确率相差 0.2 个百分点，你还希望看到哪些证据？
4. 网络训练准确率高而验证损失持续升高，说明了什么？
5. 增大 batch size 后，在固定 epoch 条件下，参数更新次数怎样变化？
